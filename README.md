## claude一键配置客户端 1.1.9

- [下载 Windows x64 EXE](https://github.com/1034142730/claude-/releases/download/business-1.1.9/Business-Client-1.1.9-win-x64.exe)

下载后双击运行，在 Windows 授权提示中选择「是」。
支持卡密激活、Claude Desktop 配置、余额查询和使用记录。

claude一键配置客户端
适用版本：Windows x64 

1. 下载与打开
下载 EXE：下载双击方式运行。

2. 首次注册
向管理员领取一次性邀请码，在欢迎页展开「注册账号或登录」：

填写账号，例如「一路向北」或「tata_user01」。
账号支持 1–20 位中文、英文字母、数字、下划线、连字符；不能填写包含 @ 或点号的邮箱。
设置 8–20 位密码，填写邀请码。
点击「使用邀请码注册」，成功后会自动尝试登录。
邀请码只用于注册，不等于额度兑换码。邀请码可能被禁用、已使用或过期，遇到提示请联系管理员。注册成功但登录失败时，使用已有账号登录，不要反复注册。

3. 已有账号登录
填写账号和密码，点击「登录已有账号」。登录无需邀请码。 正常保存后，再次打开客户端会显示「正在恢复登录」，成功后进入主页。连接失败可点击「重新连接」；如仍失败，可用原账号密码登录。

4. 兑换额度
向管理员领取额度兑换码。登录后进入「充值续费」，填写完整兑换码并提交，再查看余额是否到账。 例如备注为「50刀」的兑换码表示管理员设置的额度说明，实际到账以系统结果为准。 如提示已兑换或充值状态待确认，先刷新余额和充值记录，再联系管理员核对，不要反复提交。

5. 查询额度与使用记录
登录后在主页查看余额，并通过使用记录查看消费明细。网络异常时稍后刷新。 展示金额以系统实际返回的数据为准。

6. Claude Desktop
需要使用 Claude Desktop 时，请先安装官方程序，客户端可通过「重新检测」检查是否安装。 Windows 1.1.8 注册或登录后会自动配置 Claude Desktop；如失败，点击「重新激活」。Mac 1.1.6 暂未包含账号登录后自动激活功能，请按配置提示操作或联系管理员。

7. 更新客户端
启动时客户端会检查后台发布的版本：

可选更新：可以先继续使用，再选择更新。
强制更新：检测到新版本后，需完成更新才能继续操作。 点击更新按钮后等待下载、校验和打开新版本。失败时点击「重试」，或从本仓库 Releases 手动下载。 便携版请将新 EXE 保存在固定文件夹，之后从新文件打开。
